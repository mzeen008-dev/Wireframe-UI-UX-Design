📱 User / Guest Flow (Mobile View)
1. **Welcome & Table Detect Screen**  
   Layar awal saat pelanggan memindai QR code di meja/saung. Menampilkan konfirmasi nomor meja dan ucapan selamat datang.
2. **Menu Catalog & Filter Screen**  
   Katalog digital yang memuat daftar makanan/minuman berbasis kategori (Paket Liwet, Makanan, Minuman) beserta filter pencarian.
3. **Menu Detail & Customization Modal**  
   *Pop-up* untuk mengatur porsi, level pedas, dan catatan khusus pesanan sebelum dimasukkan ke keranjang.
4. **Checkout & Payment Method Screen**  
   Ringkasan pesanan, input nama pemesan, dan pilihan metode pembayaran (Tunai di Kasir / QRIS).
5. **Live Order Status Tracker**  
   Layar pemantauan status pesanan secara *real-time* (*Diterima* ➔ *Dimasak* ➔ *Siap Disajikan*).

---

### 🖥️ Backend Flow (Tablet & Desktop View)
1. **Kitchen Display System (KDS - Tablet Dapur)**  
   Tampilan khusus tim dapur untuk melihat pesanan masuk berbasis urutan waktu beserta tombol konfirmasi *Siap Disajikan*.
2. **Cashier POS Dashboard (Desktop Kasir)**  
   Panel kontrol kasir untuk memantau denah meja aktif, verifikasi pembayaran QRIS, dan cetak nota transaksi.
